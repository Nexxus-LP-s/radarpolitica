# Radar Política — Landing Page

Estrutura:

```
index.html              → página principal
assets/css/style.css    → estilos (responsivo + animações)
assets/js/main.js       → menu, animações de scroll, formulário
assets/img/             → logo e favicon
```

## Publicar no GitHub Pages
1. Envie **todo o conteúdo desta pasta** (não a pasta em si) para a raiz do repositório, mantendo a pasta `assets`.
2. No repositório: Settings → Pages → Source: *Deploy from a branch* → Branch `main` / `(root)` → Save.
3. Em ~1 minuto a página fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.
